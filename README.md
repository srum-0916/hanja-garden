# 글자숲 v0.3 🌿

일상에서 발견한 한자를 **찾고 → 모으고 → 외우는** 개인 한자 사전 웹사이트입니다. 모바일과 데스크톱에서 사용할 수 있습니다.

## 기능

- 홈: 통합 검색, 손글씨 / 사진 인식 바로 가기, 랜덤 발견, 최근 기록, 내 서재 통계
- 검색: 한국어 음·뜻 및 한자 검색, 한자어 검색(동음이의어 구별), 손글씨 획 인식, 스크린샷/사진 OCR
- 보관함: 한자와 한자어 개별 저장, 기존 v0.2 즐겨찾기 자동 유지
- 학습: 저장한 한자와 단어의 암기 카드, 정답 확인 및 '다시 볼래요' / '기억했어요' 선택
- 내 정보: 다크 모드, JSON 백업 및 가져오기
- 모바일 하단 5개 메뉴 / PC 왼쪽 사이드바

## 파일

`index.html` 단일 페이지. 정적 사이트로 GitHub Pages의 `main` 브랜치 루트에서 배포합니다.

## 데이터 및 한계

- 기본 한자 데이터는 HTML에 내장되어 있습니다.
- 더 많은 한자는 HanjaDB 공개 데이터 파일을 가져옵니다. 인터넷을 사용할 수 없으면 기본 한자만 검색됩니다.
- 한자어는 현재 프로젝트에 수록한 기본 목록에서만 검색됩니다. **전체 국어사전은 아닙니다.**
- 손글씨 인식: HanziLookupJS (GPL-3.0), MMAH / original data. 첫 실행시 다운로드가 필요하며 획순이나 글자 모양에 따라 정확도가 달라집니다.
- 사진 OCR: Tesseract.js (Apache-2.0), `chi_tra` 모델. 사진은 별도 서버로 전송하지 않고 브라우저에서 인식합니다. 모델 다운로드와 사용을 위해 인터넷이 필요합니다.
- 즐겨찾기, 메모, 복습 기록은 **현재 브라우저의 로컬 저장소(localStorage)**에 보관됩니다. 다른 기기와 자동으로 동기화되지 않습니다. 데이터 이동에는 백업/가져오기 기능을 사용하세요.
- 생성형 AI가 아니라 획 기반 인식 및 OCR 기술을 사용하며, 음과 뜻 및 후보는 문맥에 따라 직접 확인이 필요합니다.
- 이전 버전의 한자 즐겨찾기(`hanja-favs-v1`), 메모(`hanja-memo-v1`), 테마(`hanja-theme-v1`) 로컬 키를 그대로 사용합니다.

## 앞으로

한자어 사전 확대, 자주 틀리는 항목의 간격 반복 학습, 구성 한자 뜻 정확도 강화, Safari 실기기 인식 테스트 및 접근성 개선.
