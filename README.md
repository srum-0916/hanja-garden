# 글자숲 v0.2 · 찾고 모으고 외우는 한자

이 프로젝트는 일상에서 마주친 한자를 **검색 → 뜻 확인 → 저장 → 복습**하는 개인 한자 도구입니다. 설치가 필요 없는 모바일·PC용 정적 웹사이트입니다.

## 이번 업데이트
- **사진 인식**: 스크린샷/사진 업로드, 모바일 카메라 선택, PC 드래그앤드롭·클립보드 붙여넣기, 한자 영역 드래그 선택, 한자 OCR 후보 표시 및 상세보기 연동
- **저장한 글자 복습**: 내 글자함에서 암기 카드 시작, 뜻 가리기/보이기, 다음 글자
- **모바일 대응**: 4개 메뉴를 2×2 배치, iPhone 글자 입력 16px(자동 확대 방지), 손글씨 캔버스 포인터 입력 보완, 44px 이상의 주요 터치 버튼, 좁은 화면 대응
- 기존 검색/그림 찾기/즐겨찾기/메모/다크 모드 유지

## 이용 방법
1. `index.html`을 브라우저에서 열어 기본 검색·저장·암기 카드를 사용할 수 있습니다.
2. **사진 인식** 탭에서 사진을 선택하거나 스마트폰 카메라로 촬영합니다.
3. 필요한 부분만 드래그하면 선택 영역을, 드래그하지 않으면 전체 이미지를 인식합니다.
4. **사진 속 한자 인식하기**를 누른 뒤 후보를 선택하면 사전 데이터가 있을 때 음·뜻을 확인할 수 있습니다.
5. 마음에 드는 글자를 저장한 뒤 내 글자함에서 암기 카드를 사용합니다.

**휴대폰에서는 웹 서버에 올린 사이트를 여는 것을 권장합니다.** (예: GitHub Pages) `file://`로 파일을 직접 여는 경우 브라우저에 따라 외부 OCR worker나 저장소 제약이 있을 수 있습니다.

## 호환성 검사 (2026-11-15)
- Chromium 자동 브라우저 테스트에서 320, 360, 390, 430, 768, 1280px의 **화면 가로 넘침 없음**을 확인했습니다.
- 파일 선택, 이미지 미리보기, 드래그 영역 선택, 복습 카드, 모의 OCR 결과(꿈 몽 夢 / 꽃 화 花 / 날 일 日) 표시, 결과에서 상세화면 이동, 즐겨찾기 동작을 확인했습니다.
- **실제 iPhone Safari 실기기 테스트와 Tesseract OCR 모델을 이용한 실제 사진 인식 정확도 검증은 미완료**입니다. 자동 테스트에서 OCR은 대체 결과를 제공하는 모의 worker를 사용했습니다.

## 데이터·개인정보와 한계
- 이미지 OCR은 Tesseract.js v6.0.1의 WebAssembly 엔진을 **브라우저 내부에서 실행**합니다. 앱 자체에서 사진을 OCR 서버로 전송하지 않습니다. 최초 모델 다운로드에는 인터넷이 필요하며 모바일 네트워크/기기 성능에 따라 시간이 걸릴 수 있습니다.
- 사진 속 한자는 오인식될 수 있습니다. OCR 후보가 맞는지 반드시 확인하세요. 한국어 음·뜻이 없는 글자는 `뜻 정보 확인 필요`로 표시됩니다.
- 글자함·메모·테마는 해당 브라우저의 `localStorage`에만 저장합니다. PC와 휴대폰 사이 동기화는 아직 지원하지 않으며, 웹사이트 데이터 삭제 시 기록이 사라질 수 있습니다.
- 한국어 사전은 기본 예시 데이터와 HanjaDB의 추가 공개 데이터를 사용합니다. 모든 글자의 훈음 및 뜻을 보장하지 않습니다.
- 손글씨 찾기는 중국 한자 기준인 HanziLookupJS의 후보 추천을 사용하여 한국 고유 한자 일부를 인식하지 못할 수 있습니다.

## 오픈소스 출처
- 사진 OCR: [Tesseract.js](https://github.com/naptha/tesseract.js) (Apache-2.0)
- 손글씨 인식: [HanziLookupJS](https://github.com/gugray/HanziLookupJS) (GPL-3.0). 데이터에 별도 조건이 있을 수 있습니다.
- 한글 음·뜻 확장: [NeoMindStd/HanjaDB](https://github.com/NeoMindStd/HanjaDB). 원 자료의 권리관계에 관한 주의 문구가 있습니다. 공개 배포·상용 사용 전 원본 라이선스를 재검토하세요.
